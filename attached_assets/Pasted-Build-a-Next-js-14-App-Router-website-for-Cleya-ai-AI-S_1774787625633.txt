=== 3D & ANIMATION REQUIREMENTS ===

1. LENIS SMOOTH SCROLL: Install and configure @studio-freight/lenis for buttery smooth scrolling across the entire page. Wrap in a provider.

2. THREE.JS SCENES: Load all Three.js components with next/dynamic and { ssr: false }. Wrap in React Suspense with a clean loading fallback. Use two separate canvases:
   - Hero background: particle network constellation
   - CTA section: animated noise orb

3. FRAMER MOTION: Use for all scroll-triggered section animations. Every section should animate in as it enters the viewport — fade up, slight scale, optional blur-to-sharp. Use staggerChildren for card groups.

4. 3D TILT CARDS: Build a reusable <TiltCard> component that tracks mouse position on the card and applies perspective + rotateX/rotateY transforms. Include a moving radial gradient highlight overlay that follows the cursor.

5. SCROLL PROGRESS: Add a thin teal progress bar at the very top of the page that fills as the user scrolls.

6. PAGE TRANSITIONS: Smooth fade transitions on navigation.

7. CURSOR: Add a custom cursor — a small teal dot that follows the mouse with slight lag (lerp), and expands when hovering over interactive elements.

8. FLOATING DECORATIVE ELEMENTS: Add 2-3 small animated teal sparkle/asterisk decorations that float in the margins of the page (subtle, like the ones on the current site).

=== PERFORMANCE ===
- Lazy load all Three.js components
- Use will-change and GPU-accelerated transforms only
- Implement reduced-motion media query — disable all 3D and complex animations for users who prefer reduced motion
- On mobile (< 768px): disable 3D tilt, reduce particle count, simplify the orb to a static gradient circle, keep Framer Motion animations but simpler
- Target 60fps on modern devices
