Here's my comprehensive test report for **Cleo.ai - AI Networking Platform (Beta Test)**:

---

## Overall Impressions

The platform has a polished, professional dark-themed design and a solid foundation. The landing page is attractive, the onboarding flow is well-structured, and the admin dashboard is surprisingly feature-rich for a beta. That said, there are several bugs and UX issues worth addressing.

---

## AI Onboarding Conversation

**What works well:** The multi-step flow (persona selection → profile form → industries/details → referral source) is logical and doesn't feel overwhelming. The conversational wrapper around structured forms is a nice touch — it feels more personal than a plain signup wizard. Persona-specific forms (e.g., Investor gets Fund Name, Check Size, Investment Stage) show good attention to role differences.

**What could improve:** The conversation doesn't truly feel like a natural AI chat. It's more of a guided form-fill wrapped in chat bubbles. Each step just says "Welcome! Let's set up your profile" and then presents a form. A more conversational approach — asking one question at a time, responding to answers dynamically, or acknowledging what you've shared — would feel much more "AI-powered." As it stands, it feels like a wizard with chat UI chrome.

---

## Bugs Found

**Critical/High:**

1. **Logout redirects to 404 page.** Clicking "Log Out" in Settings redirects to `/login`, which returns a 404 "Page not found." The login functionality only exists as a modal on the homepage, not as a standalone route.

2. **Hamburger menu non-functional on mobile.** The mobile hamburger menu (☰) doesn't open any navigation panel. Users on mobile have no way to access Matches, Chat, Profile, or Settings from the dashboard — they're completely stuck.

3. **Floating chat button (💬) does nothing.** The purple chat FAB on the dashboard doesn't navigate to chat or open a widget. It appears to be completely non-functional.

4. **Profile overwrite / data integrity issue.** When I re-ran the onboarding chat on the Founder (sarah@techstartup.com) account and selected "Investor," it overwrote the persona entirely. The account changed from Founder to Investor with the new data I entered ("Horizon Ventures"). This means re-entering the chat flow can corrupt the user's existing profile.

5. **No matches generated for any account.** All 6 test accounts show 0 matches despite having complete profiles with overlapping interests (e.g., AI/ML founders and AI/ML investors). The matching engine doesn't appear to be running or producing results.

**Medium:**

6. **Analytics shows 600% onboarding rate.** The Admin → Analytics page displays "Onboarding Rate: 600%" which is clearly a math error (likely dividing complete profiles by total users incorrectly).

7. **Inconsistent user counts in admin.** The Overview tab shows 6 total users, but the Analytics tab shows 5 total users and 6 complete profiles — the numbers don't agree.

8. **Industries not pre-selected on Profile edit page.** After selecting AI/ML, SaaS, and Climate/Energy during onboarding, the Profile edit page shows all industry tags but none are visually selected/highlighted. The selected state doesn't persist to the edit view.

9. **Notification bell does nothing.** Clicking the bell icon in the nav produces no visible result — no dropdown, no empty state message, nothing.

10. **"Find Matches" quick action does nothing.** On the dashboard, clicking the "Find Matches" card doesn't navigate anywhere or trigger any action.

**Low:**

11. **"Log In" hero button on landing page doesn't work.** The secondary "Log In" button below "Get Started" on the landing page hero section doesn't open the login modal (the nav bar "Log In" works fine).

12. **Profile card text truncation on mobile.** The profile description ("Scaling engineering teams at hypergrowth companies") gets cut off on mobile without ellipsis or wrapping.

13. **Nav header overflow on mobile.** The "Get Started" button and "Log In" text in the sticky nav get cut off on small screens.

---

## What Works Well

- **Landing page design** is polished, professional, and communicates the value prop clearly
- **Admin dashboard** is impressively comprehensive with conversion funnel, persona breakdown, analytics charts, deal pipeline, events, and comms tracking
- **Onboarding form** adapts fields based on persona (Investor gets fund-specific fields)
- **Profile page** is well-organized and editable
- **Settings page** has all the essentials (account info, password change, session management, account deletion)
- **Consistent design language** — dark theme, purple accents, card-based layout
- **Multiple persona support** (Founder, Investor, Operator, Advisor, Job Seeker) with role-specific icons

---

## Suggestions

- Make the AI chat feel more conversational — ask questions one at a time, acknowledge responses, maybe add follow-up questions based on what the user says
- The matching engine is the core value — prioritize getting it to generate relevant matches between the test accounts
- Add empty states with CTAs everywhere (notifications, matches, etc.) instead of showing nothing
- Consider adding a "Suggested Connections" section on the dashboard that works even before formal matches are generated
- The 88% complete progress bar is a great motivator — show a tooltip or message explaining what's missing to reach 100%
