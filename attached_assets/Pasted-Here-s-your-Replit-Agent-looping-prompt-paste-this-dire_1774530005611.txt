BUG-08: ESCAPE KEY DOESN'T CLOSE THE MODAL
- Severity: P1 MAJOR
- Location: Auth modal component
- Problem: Pressing Escape while the modal is open does nothing.
- Fix: Add a `useEffect` in the modal component that listens for `keydown` events. When `Escape` is pressed and the modal is open, call the close handler (which should also trigger the state reset from BUG-02). Remember to clean up the event listener on unmount.
- Code pattern:
```typescript
useEffect(() => {
  const handleEsc = (e: KeyboardEvent) => {
    if (e.key === 'Escape') onClose();
  };
  if (isOpen) document.addEventListener('keydown', handleEsc);
  return () => document.removeEventListener('keydown', handleEsc);
}, [isOpen, onClose]);
```
- Acceptance Criteria: Open the modal → press Escape → modal closes and form state is reset.
