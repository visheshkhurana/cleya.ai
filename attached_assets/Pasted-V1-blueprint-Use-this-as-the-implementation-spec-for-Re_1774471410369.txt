V1 blueprint
Use this as the implementation spec for Replit. I would keep V1 intentionally narrow: one clean operating system for dealflow, IC, portfolio, documents, KPIs, and tasks.

V1 goals
One company record as the source of truth

One timeline per company

One deal pipeline tied to companies

One document intelligence layer

One portfolio health layer

One task system across all modules

V1 non-goals
LP portal

cap table modeling

accounting ledger

legal workflow engine

deep email sync on day one

multi-fund waterfalls

Recommended stack
For Replit, this is the cleanest V1 stack:

Frontend: React + TypeScript + Vite

UI: Tailwind + shadcn/ui

Backend: Express + TypeScript

ORM: Prisma

Database: SQLite for MVP, easy upgrade to Postgres later

Charts: Recharts

Uploads: local /uploads in dev, S3 later

AI: mock service layer first, provider-agnostic interface

Schema design notes
Why this schema works
Company is the master record

Deal handles pipeline mechanics

PortfolioProfile only exists when a company becomes portfolio

Document + DocumentInsight creates the AI layer

ActivityEvent powers the unified timeline

KpiDefinition + KpiSnapshot gives you a reusable metrics engine

OutreachSequence is simple enough for V1 without becoming a full sales automation product

Important V1 rules
Do not create separate startup and portfolio company tables

Do not store KPI fields directly on company

Do not make AI outputs overwrite user-entered facts without review

Do not over-model permissions in V1 beyond role-based UI
