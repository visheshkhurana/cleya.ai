You are a world-class 3D website designer working in collaboration with:
• A top-tier brand marketing agency (Apple × Stripe level)
• Elite graphic designers
• Award-winning 3D animators and motion designers

You have been given a project to completely redesign the website:
https://cleya.ai/

Your goal is to transform it into a premium, futuristic, scroll-driven 3D website that visually explains the product through motion and interaction — not static content.

---

STEP 1: UNDERSTAND PRODUCT

Cleya is an AI-powered networking and matchmaking platform.

Core flow:
People → Data → AI Matching → Connection → Opportunity

This must be visualized, not described.

---

STEP 2: BRAND REIMAGINATION

Redesign the brand identity:

• Create a refreshed, modern logo
  - Abstract symbol representing connection, intelligence, and networks
  - Minimal, geometric, scalable
  - Should work in motion (animated logo)

• Typography:
  - Clean, modern sans-serif (Apple/Inter style)
  - Strong hierarchy

• Color system:
  - Base: Obsidian black (#0A0A0A)
  - Primary: Electric blue
  - Secondary: Purple/violet accents
  - Neutral: Soft whites/greys

• Design language:
  - Premium, minimal, futuristic
  - Confident, not flashy
  - AI-native product feel

---

STEP 3: 3D EXPERIENCE DESIGN

This is NOT a normal website.

Create a cinematic 3D experience with:

• WebGL / Three.js style rendering
• Smooth scroll-driven camera movement
• Multi-layer depth and parallax
• Real-time animations

---

STEP 4: CORE VISUAL SYSTEM

Design a living AI network:

• Nodes = users
• Connections = relationships
• Pulses = data / intelligence flow

System behavior:
• Nodes appear, connect, disconnect
• AI matches create stronger glowing links
• Entire network evolves dynamically

---

STEP 5: WEBSITE STRUCTURE (3D SCENES)

1. HERO — NETWORK BIRTH
• Dark space → nodes appear → connections form
• Headline: “The AI Network That Connects You to What Matters”

2. PROFILE LAYER
• Nodes expand into floating profile cards
• Show identity becoming structured data

3. AI MATCHING ENGINE
• Central glowing AI core processes users
• Matches form dynamically between profiles

4. CONNECTION MOMENT
• Two profiles connect → chat UI appears
• Show real outcome of matching

5. USE CASES
• Floating 3D modules:
  - Founders
  - Investors
  - Talent
  - Operators

6. LIVE NETWORK
• Zoomed-out system showing constant activity

7. FINAL CTA
• Infinite network scale
• “Your next opportunity is already in the network”

---

STEP 6: ANIMATION QUALITY

• Cinematic transitions (film-like)
• No abrupt motion
• Smooth easing
• High FPS performance

Effects:
• Glow, depth-of-field, motion blur (subtle)
• Data pulses moving across connections
• Node activation on interaction

---

STEP 7: INTERACTION DESIGN

• Scroll = camera movement
• Mouse = parallax tilt
• Hover = highlight + expand
• Click = reveal deeper info

---

STEP 8: UX PRINCIPLES

• Show, don’t tell
• Minimal text, maximum visual storytelling
• Each section must demonstrate product value
• Feels like a product demo, not a landing page

---

STEP 9: OUTPUT REQUIREMENTS

Deliver:

• Interaction model
• Animation behavior
