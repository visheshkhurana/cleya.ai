Channel Playbooks

Detailed strategy for each marketing channel

in
LinkedIn — Primary Channel
5 posts/week • Thought leadership + community building

Content Mix (weekly):

• Monday: "Matching Monday" — AI-powered insight (e.g., "Founders in [city] are getting funded 2x faster this quarter")

• Tuesday: Founder spotlight or success story from the Cleya network

• Wednesday: Educational carousel (fundraising tips, investor thesis breakdowns, networking tactics)

• Thursday: Industry data/trend post (sourced from Cleya's matching data, anonymized)

• Friday: Community post — "Founder Friday" Q&A, poll, or conversation starter

Posting Times: 8:30am IST (professionals checking LinkedIn) or 12:30pm IST (lunch break)

Hashtags: #StartupIndia #FounderLife #AngelInvesting #IndianStartups #AINetworking #CleyaAI

Format Priority: Text-only > Carousel > Image > Video (based on LinkedIn algorithm 2026)

IG
Instagram — Brand & Community
3 posts/week + daily stories • Visual storytelling

Content Mix:

• Carousels (2x/week): "5 things investors look for", "How Cleya matches you", startup ecosystem data visualizations

• Reels (1x/week): Quick founder tips, behind-the-scenes, member testimonials

• Stories (daily): Polls, member shoutouts, event countdowns, "DM us to join" CTAs

Visual Style: Dark mode aesthetic, data-forward graphics, clean typography

@
Email — Nurture & Convert
Weekly newsletter + 3 ICP-specific drip sequences

Newsletter: "The Cleya Signal" — weekly digest of startup ecosystem insights, member spotlights, exclusive data

Drip Sequences:

• Founders Track (7 emails): Welcome → Why intentional networking → Fundraising tips → Member success story → Exclusive invite → Scarcity nudge → Last chance

• Investors Track (7 emails): Welcome → Deal flow preview → How AI matching works → Portfolio company data → Member testimonial → Exclusive access → Final invite

• Operators Track (5 emails): Welcome → Why startup roles are different → How Cleya matches talent → Success story → Join now

Segments in MailerLite: Founders, Investors, Operators (new groups to create)

→
Cold Outreach — Lead Generation
Multi-channel sequences via Lemlist • 40 emails + 20 LinkedIn/day

Campaign Types:

• Founder Acquisition: Target recently funded startups, accelerator alumni, active on LinkedIn

• Investor Acquisition: Target angel investors, micro-VCs, family offices active in Indian deals

• Event-Based: Post-conference outreach to attendees of TiE, TechSparks, Startup India events

Sequence Structure (4-step):

Day 1: Personalized email → Day 3: LinkedIn connection + note → Day 5: Follow-up email with social proof → Day 8: Final value-add email

SEO / GEO — Long-term Visibility
Organic search + AI search citability

Target Keywords: "startup networking India", "founder investor matching", "AI networking platform India", "angel investing platform India", "connect with investors India"

Content Strategy:

• Pillar pages: "Ultimate Guide to Fundraising in India", "How AI is Changing Startup Networking"

• Blog posts: 2x/month, SEO-optimized, 1500+ words

• FAQ schema for common founder/investor questions

GEO Focus: Structured data, authoritative citations, clear entity definitions so AI search engines cite Cleya when discussing Indian startup networking

$
Paid Ads — Accelerated Growth
LinkedIn Ads + Meta Ads for targeted member acquisition

LinkedIn Ads:

• Audience: Founders (title-based), Investors (seniority + industry), in India

• Formats: Sponsored posts (repurpose top organic), conversation ads, lead gen forms

• Budget allocation: 60% LinkedIn (higher intent B2B audience)

Meta Ads:

• Audience: Lookalike from existing members, interest-based (startups, venture capital, entrepreneurship)

• Formats: Carousel ads (member stories), video ads (platform demo), lead ads

• Budget allocation: 40% Meta (broader reach, lower CPC)

Retargeting: Website visitors who didn't sign up → "Only X spots remaining" urgency ads

Rollout Plan

4-week phased deployment to get the full system running

Week 1: Foundation (Current)

✅ Research Cleya.ai product, audience, competitors

✅ Audit all connected tools (MailerLite, Lemlist, Canva, Notion, etc.)

✅ Design complete agent architecture

→ Set up Notion content calendar and campaign tracker databases

→ Create MailerLite subscriber groups for Cleya (Founders, Investors, Operators)

→ Set up Canva brand kit for Cleya.ai

→ Create first scheduled workflows (content planning, social media)

Week 2: Content Engine

→ Launch Content Strategist agent (weekly planning)

→ Launch Social Media Manager agent (daily posts)

→ Create first 2 weeks of LinkedIn + Instagram content

→ Design initial Canva templates (post, carousel, story)

→ Write and schedule first "The Cleya Signal" newsletter

Week 3: Outreach & Email

→ Launch Email Marketing agent (newsletter + drip sequences)

→ Build 3 ICP-specific drip sequences in MailerLite

→ Launch Cold Outreach agent with first Lemlist campaign for Cleya

→ Set up lead enrichment pipeline

→ Create signup forms and landing page integrations

Week 4: Optimization & Scale

→ Launch Analytics agent (weekly reporting)

→ Run first SEO/GEO audit of cleya.ai

→ Set up paid ads strategy (LinkedIn + Meta)

→ Launch Orchestrator agent to coordinate all agents

→ First full-system weekly cycle

→ Optimize based on Week 2-3 performance data

What's Next After Week 4

Month 2: Full autonomous operation. All 8 agents running on schedule. Focus on A/B testing content formats, optimizing outreach sequences, and scaling what works.

Month 3: Advanced optimization. Paid ads campaigns live. Retargeting funnels active. SEO content publishing at scale. Community-driven growth loops (referral campaigns).

Ongoing: Continuous optimization based on Analytics agent insights. New campaign types. Expand to new channels (YouTube, Twitter/X, podcasts) as bandwidth allows.
